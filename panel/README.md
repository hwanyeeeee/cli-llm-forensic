## 3. 폰트 — 규정 충족 (해결됨)

양식 규정은 **나눔스퀘어 · KoPubWorld 7종만**, 폰트 변경 금지다.
**현재 포스터와 그림 4개 전부 나눔스퀘어로 렌더돼 있다.** 커밋된 산출물을 그대로 쓰면 된다.

폰트 경로는 `panel/panel_font.py` **한 곳**에서만 정한다. 포스터와 그림이 같은 함수를 부르므로
한쪽만 바뀌는 일이 없다(예전에 실제로 그 상태로 한 번 구워졌다).

```bash
python3 panel/panel_font.py        # 규정 폰트를 찾았는지 확인
```

### 폰트가 없는 머신에서 다시 구우려면

양식 폴더 동봉본 7종을 `~/.local/share/fonts/panel/` 에 넣고 `fc-cache -f` 를 돌린 뒤
**그림 4개와 포스터를 같이** 다시 굽는다.

```bash
python3 panel/f1_gap.py && python3 panel/f2_hero_compact.py \
  && python3 panel/fm_remote.py && python3 panel/f6_metrics.py
python3 panel/draft_a1.py
```

폰트를 못 찾으면 **죽지 않고 기본 글꼴로 떨어진다.** 대신 빌드 첫 줄에 경고가 찍히니
그 줄을 반드시 확인해라 — 규정 미충족 상태로 조용히 인쇄되는 것을 막으려는 것이다.

> 그림 스크립트는 `precision-diagram` 스킬의 `flowlib`을 쓴다. 그 스킬이 없는 머신에서는
> 그림을 다시 구울 수 없다 — 커밋된 `.jpg`/`.svg`를 그대로 쓰면 된다.

## 4. 다시 굽는 법

```bash
python3 panel/draft_a1.py          # 포스터 3벌 생성 (jpg/png/svg)
```

빌드가 끝나면 **면적 배분**과 **실물 글자 크기**를 스스로 출력한다. 둘 다 보고 넘어가라.

- 면적 배분: 각 구역이 구성안(①15 ②35 ③30 ④12 여백8) 대비 ±3% 안인지
- 실물 글자 크기: **8pt 미만이 하나라도 있으면 인쇄에서 안 읽힌다.** 경고가 뜨면 고치고 다시 굽는다

레이아웃이 넘치면 그냥 죽는다. 어느 밴드를 늘리라는 메시지까지 같이 나온다.

### 대시보드 캡처를 다시 떠야 할 때

```bash
python3 panel/capture_f5.py        # panel-f5-leak-scenario.png 재생성
```

커밋된 유출 시나리오 fixture로 서버를 띄우고 headless Chrome으로 찍는다(`google-chrome` 필요).
**캡처를 다시 뜨면 `draft_a1.py`의 `F5_CONTRAST` 크롭 좌표가 맞는지 확인해라** —
뷰포트가 달라지면 엉뚱한 줄을 집는다. 해상도가 어긋나면 빌드가 먼저 죽는다.

## 5. 수치가 낡았는지 확인

포스터 숫자는 **2026-08-22 17:20 스냅샷**으로 동결돼 있다. 코퍼스는 계속 자란다.

```bash
python3 -m pytest tests/test_panel_numbers.py -q -s
```

- 문서(`docs/AgenTrace-종합-아티팩트-분석.md`)와 F6 도식의 동결값이 서로 **일치하는지** 검사한다
- **동결값 대 현재값**을 표로 찍어준다. 2% 넘게 벌어지면 경고가 뜬다
- 경고가 떴다고 반드시 갱신할 필요는 없다 — 스냅샷 시각이 각주에 있으니 그대로 둬도 정직하다.
  갱신하려면 **문서와 F6을 같이** 고쳐야 한다(한쪽만 고치면 위 검사가 깨진다)

`python3 panel/draft_a1.py`도 끝에 그림끼리 수치가 어긋나는지 검사해 경고한다.
