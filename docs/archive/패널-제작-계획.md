## 1. 확보된 원격제어 실측 단서 (분석 착수 가능)

폰 없이도 **로컬 측 원격제어 흔적**은 이미 존재한다. 두 에이전트 모두 로컬에 상태를 남긴다.

| 에이전트 | 아티팩트 | 관측값 | 포렌식 의미 |
|---|---|---|---|
| Claude Code | `~/.claude.json` | `hasUsedRemoteControl = true`<br>`remoteDialogSeen = true`<br>`remoteControlUpsellSeenCount = 3` | **이 PC에서 원격제어를 실제 사용한 이력**이 남는다 |
| Codex CLI | `state_5.sqlite` `remote_control_enrollments` | 스키마 존재, 현재 0 rows<br>`websocket_url · account_id · app_server_client_name`<br>`server_id · environment_id · server_name`<br>`updated_at · remote_control_enabled` | 원격제어 **등록 대상·엔드포인트·활성 여부**가 DB에 적재된다 |

→ 신청서 §3.3이 "선행 연구에 전례 없다"고 한 지점의 **첫 실측 근거**. 패널의 차별점이 된다.

## 2. 모바일 분석 최소 실행안 — 통제 실험

실기기 구매 없이 **가진 폰 1대**로 오늘 착수 가능. 포렌식 표준인 전·후 스냅샷 대조.

1. **사전 스냅샷** — `~/.claude`·`~/.codex` 전체 파일 목록 + mtime + SHA-256, SQLite(main/wal/shm) 사본
2. **원격제어 세션 실행** — 로컬에서 원격제어 활성 → 폰 앱에서 명령 1건 지시(예: 특정 파일 읽기) → 에이전트가 로컬에서 실행
3. **사후 스냅샷** — 동일 수집
4. **차분 분석** — 신규/변경 파일, SQLite 신규 row, 세션 JSONL의 원격 식별 필드
5. **교차 대조** — "폰에서 지시한 시각·명령" ↔ "로컬에서 실행된 이벤트" 를 우리 도구의 Event 타임라인 위에서 결합

산출: `docs/모바일-원격제어-실측.md` + 패널용 도식 1장

**폰 측 아티팩트**는 시간이 남으면 확장 — iOS는 iTunes 백업(탈옥 불필요), Android는 adb backup/app 데이터. 안 되면 "로컬 측 규명 + 폰 측은 후속" 으로 정직하게 표기.
