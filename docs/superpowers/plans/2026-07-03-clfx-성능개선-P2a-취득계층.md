# clfx 성능개선 Phase 2a (취득계층 재설계: O9·O10·O11) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "어디서 어떻게 증거를 읽나"를 재설계 — WSL 데이터는 WSL 안에서 네이티브 파싱(9P 우회, O11), 네이티브 FS는 순차 파싱(GIL 회피, O9), 소스탐지는 hang 대신 타임아웃·표면화(O10).

**Architecture:** (1) O9: `scan_to_engine`의 파싱 태스크를 원격성(remote-ish)으로 분류 — UNC/`/mnt/`는 스레드풀(지연 중첩), 네이티브는 순차(실측: 32스레드가 순차 대비 +64% 손해). (2) O11: `\\wsl.localhost` root는 `wsl.exe` interop으로 WSL 내부에서 `clfx.wsl_helper`(같은 파서 코드)를 실행 → 결과 JSONL만 회수 → 경로를 원 표기로 재작성 → byte-identical. 실패 시 기존 UNC 직접 경로 폴백 + 사유 표면화. (3) O10: 소스탐지의 원격 존재확인에 스레드 타임아웃 → "접근 시간 초과" 경고 표면화.

**Tech Stack:** Python stdlib (subprocess, threading, tempfile, hashlib, shutil, re), vanilla JS. 서드파티 0.

**스펙:** `docs/superpowers/specs/2026-07-02-clfx-성능개선-design.md` §3 O9/O10/O11 (불변식 §0 I1~I6). 실측 근거: `docs/perf-baseline.md`.

## Global Constraints

- **stdlib-only** — 서드파티 패키지 금지.
- **I1 무손실**: 위임/순차/타임아웃 어떤 경로든 분석 출력은 기존과 byte-identical — `test_scan_equivalent_to_sequential` 무변경 통과 + 신규 등가성 테스트.
- **I2 완전성**: 위임 실패 = 폴백으로 데이터 커버 + 사유 표면화. 탐지 타임아웃 = 조용한 누락이 아니라 `warnings` 표면화. skip/cap 0.
- **I3 read-only**: 증거 파일시스템 쓰기 0. 헬퍼 스테이징·출력 파일은 **Windows 임시 디렉터리(증거 밖)** 에만. 헬퍼는 `python3 -B -E -s`(pyc 생성 금지·환경 격리)로 실행 — 증거 환경 내 발자국 최소화·문서화.
- **결정성**: 모든 출력 정렬(manifest·delegate_info). 조립 순서 = root 입력순→파일순→line순 불변.
- **I6**: timings는 기존 분리 채널 유지.
- 테스트: `python3 -m pytest tests/ -x -q`. 커밋은 태스크 단위, 커밋 전 전체 회귀.

```python
def _remote_root(root):
    """O9: 지연-계층(remote-ish) root 판정 — 스레드 중첩이 이득인 경로.
    UNC(\\wsl.localhost·\\wsl$ 등 //로 시작)와 /mnt/(WSL drvfs)는 I/O 지연 지배 → 스레드풀.

    r = str(root).replace("\\", "/").lower()
    return r.startswith("//") or r.startswith("/mnt/")
```

```python
_TIMEOUT_MSG = "접근 시간 초과 — WSL 파일공유(9P) 응답 없음. wsl --shutdown 후 재시도"


def _isdir_t(path, timeout=3.0):
    """os.path.isdir에 타임아웃 — 9P wedge 시 무한 hang 차단(2026-07-03 실사, O10).
    반환 (isdir, timed_out). 타임아웃 시 (False, True). 데몬 스레드가 남을 수 있으나
    프로세스 종료를 막지 않는다(의도적 트레이드오프 — hang보다 낫다)."""
    res = {}

    def _probe():
        try:
            res["v"] = os.path.isdir(path)
        except OSError:
            res["v"] = False

    t = threading.Thread(target=_probe, daemon=True)
    t.start()
    t.join(timeout)
    if "v" not in res:
        return False, True
    return res["v"], False


def _listdir_t(path, timeout=3.0):
    """디렉터리 나열에 타임아웃(WSL home 사용자 열거용). (이름 리스트, timed_out)."""
    res = {}

    def _probe():
        try:
            res["v"] = sorted(os.listdir(path))
        except OSError:
            res["v"] = []

    t = threading.Thread(target=_probe, daemon=True)
    t.start()
    t.join(timeout)
    if "v" not in res:
        return [], True
    return res["v"], False
```

```python
def discover_sources(candidates=None):
    """반환: [{"path","label","exists"[,"error"]}] — label=origin(wsl/windows/other), exists=디렉터리 존재.
    O10: 존재확인은 타임아웃 경유 — 원격 경로 hang 시 exists=False + error 사유(조용한 누락 금지)."""
    cands = candidates if candidates is not None else _default_candidates()
    out = []
    for c in cands:
        isdir, timed_out = _isdir_t(c)
        rec = {"path": c, "label": _origin_label(c), "exists": isdir}
        if timed_out:
            rec["error"] = _TIMEOUT_MSG
        out.append(rec)
    return out
```

```python
"""O11: WSL 내부 네이티브 파싱 헬퍼. exe(Windows)가 wsl.exe interop으로 이 모듈을 WSL에서 실행 —
\\wsl.localhost(9P)를 우회해 증거를 네이티브 FS에서 읽는다(신뢰성+속도, docs/perf-baseline.md).

증거 환경 내 발자국(라이브 포렌식 트레이드오프 — 문서화):
  - 실행: python3 -B -E -s (pyc 생성 금지, 환경변수/사이트 격리)
  - 읽기: 증거 root의 jsonl만(roio._ro_open 경유 — read-only 강제)
  - 쓰기: --out(호출자가 지정한 증거 밖 경로, 보통 /mnt/c 임시디렉터리)뿐
출력 계약: out 파일 1행 = meta JSON {"files","events","manifest","timings"}, 이후 행당 Event dict.
stdout: "TOTAL n" 1회 → 파일마다 "PROGRESS i n" (호출자 진행률 포워딩).
파싱·태깅·enrich는 scan_to_engine 직접 경로와 같은 코드·같은 순서 → byte-identical(I1)."""
import argparse
import json
import os
import sys
import time


def run(root, origin_tag, out_path):
    from clfx.sources.claude import ClaudeSource
    from clfx.parser import parse_file
    from clfx.analyze.attribution import enrich
    if not os.path.isdir(root):
        print(f"root not a directory: {root}", file=sys.stderr)
        return 2
    src = ClaudeSource(root)
    files = src.jsonl_files()                       # history 먼저 → sorted transcripts (직접 경로와 동일)
    hist = src.root / "history.jsonl"
    print(f"TOTAL {len(files)}", flush=True)
    events, bypass, manifest = [], set(), {}
    _t = time.perf_counter()
    for i, p in enumerate(files):
        evs, byp, sha = parse_file(src, p, p == hist)
        bypass |= byp
        if sha is not None:
            manifest[str(p)] = sha
        for e in evs:
            if origin_tag and origin_tag not in e.tags:
                e.tags.append(origin_tag)           # 직접 경로 조립 루프와 동일: 태그 먼저 → enrich 나중
        events.extend(evs)
        print(f"PROGRESS {i + 1} {len(files)}", flush=True)
    parse_s = time.perf_counter() - _t
    _t = time.perf_counter()
    enrich(events, src, bypass=bypass)              # 수집된 bypass로 태깅(재읽기 X) — 직접 경로와 동일
    enrich_s = time.perf_counter() - _t
    meta = {"files": len(files), "events": len(events),
            "manifest": {k: manifest[k] for k in sorted(manifest)},
            "timings": {"parse_wall_s": round(parse_s, 3), "enrich_s": round(enrich_s, 3)}}
    with open(out_path, "w", encoding="utf-8") as f:
        f.write(json.dumps(meta, ensure_ascii=False) + "\n")
        for e in events:
            f.write(json.dumps(e.to_dict(), ensure_ascii=False) + "\n")
    return 0


def main(argv=None):
    ap = argparse.ArgumentParser(description="clfx WSL-side parse helper (O11)")
    ap.add_argument("root")
    ap.add_argument("--origin-tag", default="")
    ap.add_argument("--out", required=True)
    a = ap.parse_args(argv)
    return run(a.root, a.origin_tag, a.out)


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""O11: WSL-side 파싱 위임 오케스트레이션 — \\wsl.localhost(9P) 우회.
wsl.exe interop 채널로 WSL 안에서 clfx.wsl_helper를 실행해 네이티브 파싱 결과만 회수한다.
9P가 wedge 되어도 interop은 별개 채널이라 동작(2026-07-03 실사, docs/perf-baseline.md).
read-only(I3): 증거 트리 쓰기 0 — 스테이징(헬퍼 사본)·출력(out.jsonl)은 호출측(Windows) 임시 디렉터리.
도구 무결성: 스테이징된 헬퍼 전체(.py + shim)의 SHA-256을 반환 — attestation에 표면화(chain of custody)."""
import hashlib
import json
import re
import shutil
import subprocess
import sys
import tempfile
from pathlib import Path

from clfx.event import Event


class DelegateError(Exception):
    """위임 실패 — 호출자는 UNC 직접 파싱으로 폴백하고 사유를 표면화한다(I2)."""


_UNC_RE = re.compile(r"^\\\\wsl(?:\.localhost|\$)\\([^\\]+)\\(.+)$")

_SHIM = ("import os, sys\n"
         "sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))\n"
         "from clfx.wsl_helper import main\n"
         "sys.exit(main())\n")


def parse_wsl_unc(root):
    r"""\\wsl.localhost\<distro>\<path> 또는 \\wsl$\<distro>\<path> → (distro, "/posix/path"). 아니면 None."""
    m = _UNC_RE.match(str(root))
    if not m:
        return None
    return m.group(1), "/" + m.group(2).replace("\\", "/")


def rewrite_prefix(path, src_prefix, dst_prefix):
    """경로 표기 재작성(헬퍼의 posix 경로 → 호출자가 선택한 root 표기). 프리픽스 불일치는 원문 유지.
    dst가 백슬래시 표기면 잔여 구분자도 \\로 — UNC 직접 파싱 결과와 byte-identical(I1)."""
    p = str(path)
    if not p.startswith(src_prefix):
        return p
    rest = p[len(src_prefix):]
    if "\\" in dst_prefix:
        rest = rest.replace("/", "\\")
    return dst_prefix + rest


def win_to_wsl_path(p):
    """C:\\... → /mnt/c/... (wsl.exe에 넘길 인자). 드라이브 문자 소문자화. 비-드라이브 경로는 에러."""
    m = re.match(r"^([A-Za-z]):[\\/](.*)$", str(p))
    if not m:
        raise DelegateError(f"Windows 드라이브 경로 아님: {p}")
    return "/mnt/" + m.group(1).lower() + "/" + m.group(2).replace("\\", "/")


def helper_source_dir():
    """스테이징할 clfx 패키지 소스 위치. PyInstaller onefile은 _MEIPASS/clfx_src(빌드 --add-data),
    개발/테스트는 설치된 패키지 디렉터리 자체."""
    base = getattr(sys, "_MEIPASS", None)
    if base:
        cand = Path(base) / "clfx_src"
        if (cand / "wsl_helper.py").exists():
            return cand
    import clfx
    return Path(clfx.__file__).parent


def stage_helper(workdir):
    """workdir에 clfx 패키지 사본 + 실행 shim(run_helper.py) 기록. (shim_path, sha256_hex) 반환.
    sha256 = shim + 패키지 전체 .py(상대경로+내용, 정렬)의 결합 해시 — 결정적(도구 무결성 표면화용).
    web/(정적 UI)은 헬퍼에 불필요해 제외 — 스테이징 최소화."""
    workdir = Path(workdir)
    workdir.mkdir(parents=True, exist_ok=True)
    pkg_dst = workdir / "clfx"
    shutil.copytree(helper_source_dir(), pkg_dst,
                    ignore=shutil.ignore_patterns("__pycache__", "*.pyc", "web"))
    shim_path = workdir / "run_helper.py"
    shim_path.write_text(_SHIM, encoding="utf-8")
    h = hashlib.sha256()
    h.update(_SHIM.encode("utf-8"))
    for f in sorted(pkg_dst.rglob("*.py")):
        h.update(str(f.relative_to(pkg_dst)).replace("\\", "/").encode("utf-8"))
        h.update(f.read_bytes())
    return shim_path, h.hexdigest()


def delegate_root(root, origin_label, on_progress=None, runner=None, workdir=None):
    """root(WSL UNC)를 WSL 내부에서 파싱해 회수. 반환 dict:
    {"events": [Event...(태그+enrich 완료, source.file은 원 UNC 표기)],
     "manifest": {원표기 jsonl path: sha256} (정렬), "timings": {...}, "helper_sha256": hex}.
    runner: 헬퍼 실행 argv 프리픽스(테스트 주입용) — None이면 wsl.exe interop."""
    parsed = parse_wsl_unc(root)
    if parsed is None:
        raise DelegateError(f"WSL UNC 아님: {root}")
    distro, posix_root = parsed
    return _run_staged(posix_root, str(root), origin_label, distro=distro,
                       on_progress=on_progress, runner=runner, workdir=workdir)


def _run_staged(posix_root, target_root, origin_label, distro=None,
                on_progress=None, runner=None, workdir=None):
    """스테이징→실행→회수→경로재작성 코어. runner=None이면 wsl.exe(-d distro) 경유(distro 필수)."""
    own_tmp = workdir is None
    workdir = Path(workdir) if workdir else Path(tempfile.mkdtemp(prefix="agentrace-delegate-"))
    try:
        shim, helper_sha = stage_helper(workdir)
        out_path = workdir / "out.jsonl"
        origin_tag = f"origin:{origin_label}"
        if runner is None:
            if not distro:
                raise DelegateError("distro 미지정(wsl.exe 실행 불가)")
            argv = ["wsl.exe", "-d", distro, "--", "python3", "-B", "-E", "-s",
                    win_to_wsl_path(shim), posix_root,
                    "--origin-tag", origin_tag, "--out", win_to_wsl_path(out_path)]
        else:
            argv = list(runner) + [str(shim), posix_root,
                                   "--origin-tag", origin_tag, "--out", str(out_path)]
        try:
            proc = subprocess.Popen(argv, stdout=subprocess.PIPE, stderr=subprocess.PIPE,
                                    text=True, encoding="utf-8", errors="replace")
        except OSError as e:
            raise DelegateError(f"헬퍼 실행 불가: {e}")
        for line in proc.stdout:                    # TOTAL/PROGRESS 스트림 포워딩
            parts = line.split()
            if len(parts) == 2 and parts[0] == "TOTAL" and parts[1].isdigit():
                if on_progress:
                    on_progress(0, int(parts[1]))
            elif len(parts) == 3 and parts[0] == "PROGRESS" and parts[1].isdigit():
                if on_progress:
                    on_progress(int(parts[1]), int(parts[2]))
        stderr_tail = (proc.stderr.read() or "")[:300]
        rc = proc.wait()
        if rc != 0:
            raise DelegateError(f"헬퍼 rc={rc}: {stderr_tail}")
        try:
            lines = out_path.read_text(encoding="utf-8").splitlines()
        except OSError as e:
            raise DelegateError(f"출력 회수 실패: {e}")
        if not lines:
            raise DelegateError("헬퍼 출력이 비어있음")
        try:
            meta = json.loads(lines[0])
        except json.JSONDecodeError as e:
            raise DelegateError(f"meta 파싱 실패: {e}")
        events = []
        for ln in lines[1:]:
            if not ln.strip():
                continue
            d = json.loads(ln)
            d["source"]["file"] = rewrite_prefix(d["source"]["file"], posix_root, target_root)
            events.append(Event.from_dict(d))
        if len(events) != meta.get("events"):
            raise DelegateError(f"이벤트 수 불일치: meta={meta.get('events')} 실제={len(events)}")
        manifest = {rewrite_prefix(k, posix_root, target_root): v
                    for k, v in (meta.get("manifest") or {}).items()}
        return {"events": events,
                "manifest": {k: manifest[k] for k in sorted(manifest)},
                "timings": meta.get("timings") or {},
                "helper_sha256": helper_sha}
    finally:
        if own_tmp:
            shutil.rmtree(workdir, ignore_errors=True)
```

참고: `Event.to_dict()`는 dataclass `asdict` 기반이라 source가 `{"source": {"file":..., "line":...}}` 중첩 dict로 직렬화됨(event.py:62-64 확인 완료) — `d["source"]["file"]` 재작성이 정확하다. `Event.from_dict`는 전체 키 요구 + tags None 정규화(event.py:70-76) — to_dict 왕복은 무손실.

```python
            enrich(root_evs, srcs[ri], bypass=bypass_by_root[ri])   # 수집된 bypass로 태깅(재읽기 X)
            t_enrich += time.perf_counter() - _t
        events.extend(root_evs)
        if collect_artifacts:
            ev_root.extend((e, str(root)) for e in root_evs)
            for e in root_evs:
                for t in e.tags:
                    if t.startswith("origin:"):
                        k = t[len("origin:"):]
                        by_origin[k] = by_origin.get(k, 0) + 1
```
