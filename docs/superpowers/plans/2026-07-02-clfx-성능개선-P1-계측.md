# clfx 성능개선 Phase 1 (계측 하네스) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 스캔·서버·LLM·프런트 전 구간에 단계별 타이밍 계측을 넣고, 실데이터 벤치 스크립트로 병목 순위표(`docs/perf-baseline.md`)를 만들 수 있게 한다.

**Architecture:** 계측은 전부 "곁길"이다 — 분석 출력(증거 데이터)은 1바이트도 안 바뀐다. 타이밍은 ① `forensic_scan` 반환값의 별도 `timings` 키(서버가 pop, `/api/artifacts` 미노출) ② 엔진 부착 속성 `parse_timings` ③ `/api/scan/progress`의 `timings` 필드 ④ stderr `[clfx.timing]` 로그 ⑤ `query_payload`의 별도 `timings` 키 ⑥ 브라우저 `performance.mark`/console — 이 6개 통로로만 흐른다.

**Tech Stack:** Python stdlib (`time.perf_counter`, `statistics.median`, `argparse`), vanilla JS (`performance` API). 서드파티 0.

**스펙:** `docs/superpowers/specs/2026-07-02-clfx-성능개선-design.md` §1 (불변식 §0 I1~I6)

## Global Constraints

- **stdlib-only** — 서드파티 패키지 금지.
- **I6 계측 분리**: 타이밍 값은 비결정적 → 증거 페이로드(`/api/artifacts`, `/api/events`, attestation 등)에 절대 미포함. `timings`는 별도 키/필드/stderr에만. 등가성 테스트는 `timings` 제외 후 비교.
- **I1 무손실**: 계측 추가 전/후 분석 출력 동일 — 기존 전체 테스트(376+) green 유지. `test_scan_equivalent_to_sequential` 무변경 통과.
- **I3 read-only**: 계측이 FS 접근을 추가하지 않는다 (perf_counter·print만).
- **결정성**: `timings`의 키 집합·구조는 결정적(값만 비결정 허용).
- 테스트 실행: `python3 -m pytest tests/ -x -q` (개별은 `python3 -m pytest tests/test_timings.py -v`).
- 커밋은 태스크 단위. 커밋 전 전체 회귀 필수.

import json
import threading
import urllib.request
import urllib.error
from http.server import ThreadingHTTPServer

from clfx.query.engine import QueryEngine
from clfx.web.api import forensic_scan, scan_to_engine
from clfx.web.server import make_handler, ServerState

FORENSIC_TIMING_KEYS = {"walk_tmp_s", "resolve_s", "hash_s", "attribution_s", "retention_s"}


def _server_with(state):
    httpd = ThreadingHTTPServer(("127.0.0.1", 0), make_handler(state))
    threading.Thread(target=httpd.serve_forever, daemon=True).start()
    return httpd


def _get(httpd, path):
    port = httpd.server_address[1]
    with urllib.request.urlopen(f"http://127.0.0.1:{port}{path}") as r:
        return r.status, r.read().decode("utf-8")


def _post(httpd, path, obj):
    port = httpd.server_address[1]
    data = json.dumps(obj).encode("utf-8")
    req = urllib.request.Request(f"http://127.0.0.1:{port}{path}", data=data,
                                 headers={"Content-Type": "application/json"}, method="POST")
    with urllib.request.urlopen(req) as r:
        return r.status, r.read().decode("utf-8")


def test_forensic_scan_returns_timings():
    out = forensic_scan([], roots=[], tmp_dirs=[])
    t = out["timings"]
    assert set(t) == FORENSIC_TIMING_KEYS
    assert all(isinstance(v, float) and v >= 0.0 for v in t.values())


def test_artifacts_payload_has_no_timings():

    finally:
        httpd.shutdown()

`forensic_scan` 본문의 스테이지 블록(현재 269-297행)을 아래로 교체 — 각 스테이지를 `time.perf_counter()`로 감싼다 (기존 로직·주석·`_emit` 순서 불변):

```python
    timings = {}

    # 1) walk-tmp: 단일 인벤토리(재-walk 금지 — 이후 전 단계 공유).
    _emit("walk-tmp", 0, 1)
    _t = time.perf_counter()
    inventory = artifacts.build_tmp_inventory(tmp_dirs)
    timings["walk_tmp_s"] = round(time.perf_counter() - _t, 3)
    _emit("walk-tmp", 1, 1)

    # 2) resolve: (root,target) 해석 캐시 1회(hash_clusters·attribution_join 공유 — 중복 resolve 제거).
    _emit("resolve", 0, 1)
    _t = time.perf_counter()
    resolved = artifacts.build_reference_resolution(events_with_root)
    timings["resolve_s"] = round(time.perf_counter() - _t, 3)
    _emit("resolve", 1, 1)

    # 3) hash: size-prefilter 해싱(N/M 진행은 hash_clusters의 on_hash_progress가 forward).
    _emit("hash", 0, 0)
    _t = time.perf_counter()
    out = artifacts.hash_clusters(events_with_root, roots=roots, tmp_dirs=tmp_dirs,
                                  inventory=inventory, resolved=resolved,
                                  on_hash_progress=lambda d, t: _emit("hash", d, t))
    timings["hash_s"] = round(time.perf_counter() - _t, 3)

    # 4) attribution(공유 resolved).
    _emit("attribution", 0, 1)
    _t = time.perf_counter()
    out["attribution"] = artifacts.attribution_join(events_with_root, resolved=resolved)
    timings["attribution_s"] = round(time.perf_counter() - _t, 3)
    _emit("attribution", 1, 1)

    # 5) retention(공유 inventory — 재-stat 금지; referenced map으로 transcript 귀속 JOIN).
    #    referenced는 hash_clusters가 이미 만든 rec — 재집계/재해시 없이 재사용.
    _emit("retention", 0, 1)
    _t = time.perf_counter()
    ret = artifacts.tmp_retention(tmp_dirs, inventory=inventory,
                                  referenced=out.get("referenced"))
    out["retention"] = ret["retention"]
    out["errors"] = sorted(out["errors"] + ret["errors"], key=lambda e: e["path"])  # 보존 스캔 실패도 병합
    timings["retention_s"] = round(time.perf_counter() - _t, 3)
    _emit("retention", 1, 1)
```

"""clfx 성능 벤치 — 실데이터 스캔을 N회 반복해 단계별 median 마크다운 표 출력.

사용:  python3 scripts/bench.py <root> [<root>...] [--repeat 3]
       (Windows: py -3 scripts\\bench.py C:\\Users\\<u>\\.claude \\\\wsl.localhost\\Ubuntu\\home\\<u>\\.claude)

테스트 아님(환경 의존 시간값) — CI 밖 수동 실행. 결과는 docs/perf-baseline.md에 붙여넣는다.
read-only: 스캔 대상은 읽기만(roio 가드 유지), 출력은 stdout뿐 — 어디에도 쓰지 않는다."""
import argparse
import os
import statistics
import sys
import time

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))  # repo 루트

from clfx.web.api import scan_to_engine, forensic_scan, mcp_payload  # noqa: E402

# 표 출력 순서(파이프라인 순). 없는 키는 건너뛰고, ORDER 밖 키는 뒤에 이름순.
ORDER = ["parse_wall_s", "enrich_s", "walk_tmp_s", "resolve_s", "hash_s",
         "attribution_s", "retention_s", "mcp_s", "total_s"]


def run_once(roots):
    """스캔 1회 — (timings dict, 규모 meta dict). 서버 경로(scan_to_engine+forensic_scan+mcp)와 동일 순서."""
    t0 = time.perf_counter()
    eng, ev_root, _by, _man = scan_to_engine(roots, collect_artifacts=True)
    t = dict(getattr(eng, "parse_timings", {}))
    out = forensic_scan(ev_root, roots=roots)
    t.update(out.get("timings") or {})
    _t = time.perf_counter()
    mcp_payload(eng, roots)
    t["mcp_s"] = round(time.perf_counter() - _t, 3)
    t["total_s"] = round(time.perf_counter() - t0, 3)
    meta = {"events": len(eng.events), "scanned": out.get("scanned", 0),
            "tmp_scanned": out.get("tmp_scanned", 0), "missing": out.get("missing", 0)}
    return t, meta


def median_table(runs):
    """단계별 median. 어떤 run에 없는 키는 0.0으로 취급(결정적)."""
    keys = sorted({k for r in runs for k in r})
    return {k: round(statistics.median([r.get(k, 0.0) for r in runs]), 3) for k in keys}


def fmt_md(med, meta):
    """median dict → 마크다운 표(ORDER 순, 나머지 이름순) + 규모 메타 1줄."""
    keys = [k for k in ORDER if k in med] + sorted(k for k in med if k not in ORDER)
    lines = ["| 단계 | median(s) |", "|---|---|"]
    lines += [f"| {k} | {med[k]} |" for k in keys]
    lines.append("")
    lines.append("규모: " + " · ".join(f"{k}={v}" for k, v in sorted(meta.items())))
    return "\n".join(lines)


def main(argv=None):
    ap = argparse.ArgumentParser(description="clfx 스캔 벤치(단계별 median)")
    ap.add_argument("roots", nargs="+")
    ap.add_argument("--repeat", type=int, default=3)
    args = ap.parse_args(argv)
    runs, meta = [], {}
    for i in range(args.repeat):
        t, meta = run_once(args.roots)
        runs.append(t)
        print(f"# run {i + 1}/{args.repeat}: total={t.get('total_s')}s", file=sys.stderr)
    print(fmt_md(median_table(runs), meta))
    return 0


if __name__ == "__main__":
    sys.exit(main())
